# sneaker

Conwerse — a responsive sneaker store landing page built with React, Vite and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Structure

- `src/data.js` — products, prices, hero slides, footer links
- `src/index.css` — color and font tokens (`@theme`)
- `src/components/` — Navbar, Hero, PromoCards, ProductSection, BentoCollections, CTABanner, Footer
